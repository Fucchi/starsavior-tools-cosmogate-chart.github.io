# ダメージ計算 仕様検証ドキュメント

本ツールの「推定ダメージ」「実効ATK逆算」に使われている計算式は、根拠となった検証記録が残っておらず
信用できる前提として扱わない。まずは数式の話をする前に、ダメージ計算に関わりうる要素そのものを
ゼロベースで洗い出し、各要素について「実在するか／このツールが今どう扱っているか／未確認か」を整理する。

数式の組み立ては、この要素整理が一通り終わってから着手する。

`characters_skills.csv` の項目別チェック（[スキル確認用.txt](./スキル確認用.txt)、全37キャラ確認済み）とは別枠。あちらは
「スキルのCT・強靭削り・atk_pct・バフ効果がwikiと一致しているか」の検証で、こちらは「実際のダメージ数値がどういう
要素の組み合わせで決まるか」を扱う。

## 1. ダメージ計算に関わりうる要素の洗い出し

status の意味：
- ✅確認済み＝根拠のある事実として扱ってよい
- ⚠未実装＝ゲーム内に存在すること自体はコード中のnote等から確認できるが、本ツールの計算には組み込まれていない
- ❓不明＝存在するかどうか・どう影響するかも含めて未確認

### A. 攻撃側（自キャラ）の要素

| 要素 | status | 備考 |
|---|---|---|
| 生ステータスATK | 一部✅確認済み | 本ツールはキャラの生ATK・レベル・装備を一切管理していないが、4キャラ分の実測値が判明（4章4-4参照：セイラ12,067／ティリア11,579／バニークレア12,700／ベルリース8,254）。この生ATKと「実効ATK」（実測ダメージからの逆算値）が一致するか、それとも実効ATKには他要素が織り込まれた見かけ値なのかは要クロスチェック |
| スキル倍率%（atk_pct） | ✅確認済み | 「スキルレベル1時点の基礎倍率」で統一登録されている（クラリッサでの照合により確定。[スキル確認用.txt](./スキル確認用.txt)） |
| 攻撃力%バフ（atkModPct相当） | ⚠未実装/仮 | 現状ツールは複数バフの%を単純加算してから1回だけ乗算（`computeAtkBuffPct`）。合成方式が実ゲームと一致するかは未検証 |
| 与ダメージ%バフ（atkModPctとは別枠） | ⚠未実装／仮説あり（裏付けあり） | 「攻撃力バフ」とは独立した「与ダメージ+X%」系の効果がゲーム内に存在する（例：★挑戦 段階3以上の「スキル使用後、与ダメージ+5%スタック」＝コード内で「参考表示のみ・ダメージ計算には未反映」と明記。他に太陽属性キャラの跳躍関連スキルにも同種の言及あり）。現状の計算式にはこの項が丸ごと存在しない。<br>**仮説**：この系統のバフは会心ダメージ倍率とは別の独立した乗算項ではなく、**会心ダメージ率と同じ「加算グループ」に属し合算されてから1回だけ掛かる**（＝`1 + critDmgPct%/100 + 与ダメ増加%/100` のような形）のではないか。<br>**根拠**：ドレスアセラで無バフ時ダメージ約11600（会心時、当時の会心ダメ率はおそらく100〜130%）に対し、ダメージ+25%バフを付けても約12800止まり。もし与ダメ増加%が独立した乗算項なら11600×1.25＝約14500になるはずだが届いていない。一方「会心ダメ率と加算合成」モデルで逆算すると、会心ダメ率100%なら基礎値X=5800→新ダメージ=X×(1+1.0+0.25)=13050、130%ならX=5043→新ダメージ=X×(1+1.3+0.25)=12861となり、実測の約12800にかなり近い範囲に収まる。<br>1データ点・全て概算値のため確定ではないが、単純な独立乗算モデルより「加算グループ」モデルの方が実測に近く、仮説として有力 |
| バースト限定ダメ%（burstDamagePct） | ⚠未実装/仮 | 「バースト時のみ・会心ダメには乗らない」という前提でコードに実装されているが、これも根拠不明の仮定 |
| 会心率 | ⚠未実装（意図的） | 会心が発生するか自体は本ツールで計算しておらず、プレイヤーが実際の画面を見て判断する運用。ダメージ計算上は「会心時/非会心時」の分岐だけを扱う |
| 会心ダメージ率（critDmgPct＋critDmgModPct） | ✅確認済み（基礎値の経緯）／実測値と要クロスチェック | 会心時の倍率は「攻撃力バフ」ではなく「クリティカルダメージ率」の反映＝`1+critDmgPct/100`であることを確認。基礎値は当初10%で、会心が発生してもダメージがほとんど伸びなかったが、その後のバランス調整で基礎値50%に変更され、会心時にダメージが伸びるようになった、という運営側の変更経緯がある。現行ツールが仮定している基礎値50%はこの改定後の値と一致するが、全キャラ一律50%か（キャラ間で基礎値の差がないか）はまだ未確認。4章4-4で判明した現在の実測値（セイラ137.85%／ティリア102%／バニークレア141%／ベルリース86%）はキャラ間で大きくばらついており、基礎値50%＋キャラごとの投資状況（凸・育成・装備等）の差と考えられる。ただし4章4-2の旧データ（コスモゲート検証）から逆算した会心倍率は、この実測値よりベルリースはほぼ一致・ティリア/バニクレは大きく下振れしており、旧データが別の時点（会心ダメ率がもっと低かった頃）のものである可能性が高い（5章参照） |
| スキル強化によるダメージ上昇倍率 | ⚠未実装 | atk_pctとは別に、スキルレベルを上げることで得られる「与ダメージ+X%」的な倍率が存在する（[スキル確認用.txt](./スキル確認用.txt)の「スキルレベル最大強化時の追加効果」参照、例：基本スキル与ダメ+15%等）。atk_pctは常にLv1基礎値で統一登録する方針のため、このスキル強化分は現状どの数値にも反映されておらず、実際のダメージ計算式からは丸ごと欠落している |
| 属性（太陽/星/月/秩序/混沌） | 一部✅確認済み | 太陽/星/月の三すくみ＋秩序⇔混沌の相互有利という属性相性は実装済み（`hasElementAdvantage`）。ただし現状ツールでは**強靭削り+1**にのみ適用されており、HPダメージそのものへの倍率補正があるかどうかは未確認 |
| 役割（ロール：ストライカー/アサシン/ディフェンダー等） | ❓不明 | トリガー発動条件等には関与するが、ダメージ量そのものへの関与は未確認 |
| 会心率+会心ダメ系の複合バフ | ⚠未実装 | 「戦略指揮（会心率+会心ダメ%）」のように会心率側は「本ツール未反映」と明記されている例あり |

### B. 防御側（敵/ボス）の要素

| 要素 | status | 備考 |
|---|---|---|
| 被ダメ減少%（starDamageReductionPct） | ⚠未実装/仮 | 「★被ダメ減少」として乗算項に組み込まれているが、由来・合成方式が未検証 |
| 被ダメ増加デバフ%（dmgTakenMultPct） | ⚠未実装/仮 | タイムパラドックス等、デバフとして付与される「被ダメ+100%」等。被ダメ減少%との合成順序は未検証 |
| 防御力（DEF） | ⚠未実装／方向性は概ね掴めた | コズミックゲート強化の`defPct`が「参考表示のみ・計算には未使用」と明記されている他、攻撃力バフ/デバフと対になる**防御力バフ/デバフ（DEF増減のステータス補正）**も実在することを確認。4章のデータから3点の手がかりが得られた：①HARD難易度は「ダメージ＝ATK×atk_pct%」だけでほぼ説明できる（倍率≈1.0、ベルリースの直接照合より）、②同じHARDでDEF-30%デバフを乗せると倍率≈1.16〜1.18、③EASY難易度は倍率≈1.485（5章参照）。DEFが下がるほど倍率が伸びるという方向性・スキルに依存せず一律にかかる乗算項らしいという点までは分かったが、DEFの実数値と倍率を結ぶ正確な変換式はまだ未確定。次回コスモゲート開催時（防御力5%刻み仕様）により精密なデータが取得できる見込み |
| 防御%無視（防御力貫通） | ⚠未実装 | 対象の防御力の一部または全部を無視して攻撃するスキル/効果（「防御〇%無視」）が存在する。DEF自体がどういう式でダメージに効くかが決まらないと、この「無視%」がどこにどう作用するかも定義できないため、DEFの式とセットで検証する必要がある |
| 属性・役割相性 | ❓不明 | Aと同様、攻撃側属性/役割との相性補正が存在するか未確認 |
| EVADE（回避）成立時のダメージ軽減 | 一部✅確認済み／軽減量❓不明 | **EVADEは完全回避ではない**＝HPダメージ自体は入ることを確認。現状ツールが前提としていた「EVADE＝ダメージ0」は誤り。確認済み：①会心にはならない（強制非会心）、②強靭度ダメージは入らない（強靭削り0）。未確認：③HPダメージが軽減されるかどうか、軽減されるとしたら何%か・何の式で決まるか（固定%軽減／回避率に比例／他ステータス依存等）。EVADE時のダメージ式は通常ヒット時の式とは別立てで用意する必要がある |
| 強靭度状態（通常/ブレイク中） | ❓不明 | ブレイク中は被ダメ増加等のボーナスがあるか未確認（`breakDmgPct`というフィールドがboss dataに存在＝ブレイク時の強靭削り増加量らしきものだが、HPダメージへの影響かどうかは未確認） |
| 免疫・効果耐性 | 区別要確認 | デバフ無効化系の仕組みであり、ダメージ量そのものとは別軸の可能性が高いが念のため要整理 |

## 2. 参考：現状ツールの実装（未検証の叩き台、鵜呑みにしないこと）

`estimateDamage` / `reverseCalcEffectiveAtk`（[index.html:411](../index.html#L411)）にコメントで書かれている式。
「ユーザー検証結果に基づく」とあるのみで根拠の記録はなく、1章の要素のうち何を採用し何を無視しているかを机上で
書き出しただけの叩き台として扱う。

```
通常ダメージ = 実効ATK × (スキル倍率%/100) × (1+自身の攻撃力バフ%/100) × (1+バースト限定ダメ%/100・バースト時のみ) × (1-ボス被ダメ減少%/100) × (1+被ダメ増加デバフ%/100)
会心ダメージ = 実効ATK × (スキル倍率%/100) × (1+自身の攻撃力バフ%/100) × (1+会心ダメ%/100)          × (1-ボス被ダメ減少%/100) × (1+被ダメ増加デバフ%/100)
```

この式には1章の「与ダメージ%バフ」「防御力」「属性相性」「役割相性」等が丸ごと含まれていない点に注意。

## 3. 次のステップ

1. 1章の表を埋めるための情報源を確定する（wiki記載の仕様説明文、実測データ、公式からの言及等）。
2. ❓不明の項目から優先度をつけて、存在有無だけでも先に白黒つける（存在しないなら式に入れる必要がない）。
3. 存在が確認できた要素について、どういう式で効くか（乗算/加算、合成グループ）を実測データで検算する。
4. 要素と式の形がある程度固まった段階で、既存の「🧮 ダメージ検証ツール」（`dmgTestEntries`、[index.html:445](../index.html#L445)）
   を使い、対照実験形式でデータを集めて数式を検証する。

| ベルリース基本 | 5,412 | 6,162 | ×1.139（+13.9%） |
| バニクレ基本 | 8,046 | 9,575 | ×1.190（+19.0%） |
| バニクレ特殊 | 9,852 | 11,370 | ×1.154（+15.4%） |
| ベルリース特殊 | 5,356 | 6,434 | ×1.201（+20.1%） |
| ティリア特殊 | 14,574 | 17,866 | ×1.226（+22.6%） |
| ベルリース究極 | 9,388 | 10,960 | ×1.168（+16.8%） |

会心側でも、4-2の平均会心/非会心比率を使って通常時の会心ダメージを概算し、4-3の会心実測値と比較すると、+11.8%〜+20.8%（平均+16.5%程度）で同様の傾向。

→ **DEF-30%はダメージを一律+30%にはせず、概ね+12%〜+23%（平均+16〜18%程度）しか増加させていない**。DEFとダメージが単純な1次関係でないことがここから分かる。よくあるパターン（防御力が「軽減率」に非線形変換される、例：軽減率=DEF/(DEF+定数) 等）と矛盾しない結果だが、通常時のDEF軽減率の絶対値が分からないと式は一意に決まらない。優先度の高い追加検証候補。

> 📌 **今後の検証予定**：次回コスモゲート開催時に再度この検証を行う予定。仕様変更後は防御力が5%刻みで上昇していく形式になったため、
> 今回のような1点（-30%）だけでなく、DEF差分と倍率の対応関係を段階的に複数点取得できる見込み。これが取れればDEFの変換式を
> かなり正確に特定できる（5-3で分かった「HARD≈基準値、EASY≈+48.5%」という大づかみな傾向を、実際の数式にまで落とし込める）。
>
> **編成案**：パーティーは4体編成できるため、次回はatk_pctの異なる4キャラを同時に採用し、同じDEF段階ごとに4キャラ分の
> 実測データを一度に取る（可能なら4キャラともatk_pct登録済み・生ATK判明済みのキャラを選ぶと、5-3と同じ直接照合ができる）。
> こうすることで、DEF段階ごとの倍率が「キャラ・スキルによらず本当に一律なのか」（＝防御力はスキル非依存の単純な乗算項という
> 5-3の仮説の裏付け）を、1体だけでなく複数キャラ・複数atk_pct値で同時に確認できる。もし4キャラ間で倍率がズレるようなら、
> 防御力以外にキャラ／スキルごとの要素が別途乗っている、という反証にもなる。

### 5-3. ベルリースの生ATK×atk_pctとの直接照合

ベルリースは`characters_skills.csv`にatk_pctが登録済み（基本65%／特殊60%／究極115%）で、4-4で生ATK（8,254）も判明している唯一のキャラ。
「ダメージ ＝ ATK × atk_pct%」という最も単純な式を基準にした場合の予測値と、4-1の実測値（非会心）を比較する：

| スキル | atk_pct | 予測値(ATK×atk_pct%) | HARD実測 | HARD倍率 | EASY実測 | EASY倍率 |
|---|---|---|---|---|---|---|
| 基本 | 65% | 5,365 | 5,412 | ×1.009（+0.9%） | 7,806 | ×1.455（+45.5%） |
| 特殊 | 60% | 4,952 | 5,356 | ×1.082（+8.1%） | 7,494 | ×1.513（+51.3%） |
| 究極 | 115% | 9,492 | 9,388 | ×0.989（-1.1%） | 14,117 | ×1.487（+48.7%） |

**読み取れること**：
- **HARD難易度は3スキルとも倍率がほぼ1.0（0.99〜1.08、平均1.03）**＝「ダメージ＝ATK×atk_pct%」という最もシンプルな式だけで、
  HARD実測値をほぼ説明できてしまう。つまりHARDのボスは（今回検証したベルリースに対しては）ほぼ「防御力による軽減がニュートラル」
  に近い状態と考えられる。
- **EASY難易度は3スキルとも倍率がほぼ一定（1.455〜1.513、平均1.485）**＝スキルによらず一律で約+48.5%増加。これはEASYのボスの
  防御力がHARDより低く、その分ダメージが一律に伸びている（＝防御力の効果はスキルの種類に依存しない、単純な乗算項である）ことを
  強く示唆する。
- 5-1の「DEF-30%で+16〜18%」という結果と合わせると、DEF（防御力）を下げるほどダメージの倍率が伸びていく、というシンプルで一貫した
  方向性の中に、HARD（倍率≈1.0）・DEF-30%（倍率≈1.16〜1.18）・EASY（倍率≈1.485）という3点が並ぶ形になる。DEFの実数値が分かれば
  この3点から変換式をかなり絞り込めそう（📌の今後の検証予定を参照）。

4-4で判明した「現在の」会心ダメージ%から会心倍率(`1+critDmgPct/100`)を計算し、4-2の「コスモゲート検証時点」の会心/非会心比率（各スキルの3難易度平均）と比較：

| キャラ | 4-4実測の会心倍率 | 4-2基本(平均) | 4-2特殊(平均) | 4-2究極(平均) |

**読み取れること**：

## 6. 検証ログ（結論が出たものをここに追記）

- **会心ダメージ率の基礎値**：会心時の倍率は「クリティカルダメージ率」の反映（`1+critDmgPct/100`）であり、攻撃力バフとは別枠。
  基礎値は当初10%だったが、その後のバランス調整で50%に変更され、会心時のダメージが実際に伸びるようになった経緯がある。
  現行ツールの仮定値（基礎値50%）は改定後の値と一致。ただし全キャラ一律かは未確認（A表参照）。
- **属性有利の適用範囲**：太陽/星/月の三すくみ＋秩序⇔混沌の相互有利は実装済みだが、現状は強靭削り+1にのみ適用。
  HPダメージへの属性相性補正があるかどうかは別途未確認（A表参照）。
- **EVADE（回避）は完全回避ではない**：EVADE成立時もHPダメージは入る。現状ツールの「EVADE＝ダメージ0」という前提は誤りと判明。
  確定しているのは「非会心固定」「強靭度ダメージ0」の2点のみで、HPダメージが軽減されるか・されるならどの式かは未確認のまま（B表参照）。
- **与ダメージ増加系バフは会心ダメージ率と「加算グループ」で合成されている疑い（仮説・裏付けあり）**：ドレスアセラの過去実測で、
  無バフ時ダメージ約11600（会心時、当時の会心ダメ率はおそらく100〜130%）→ダメージ+25%バフ付与後は約12800止まり。
  独立した乗算項なら11600×1.25≈14500になるはずが届いていない。`1+critDmgPct%+与ダメ増加%`という1本の加算グループとして
  合成されるモデルで逆算すると、会心ダメ率100〜130%の範囲で新ダメージは約12860〜13050となり、実測の約12800にかなり近い。
  1データ点・概算値のみで確定ではないが、独立乗算モデルより有力な仮説（A表参照）。
- **防御力ダウン30%の実効果は+30%ではなく+12%〜+23%程度（平均+16〜18%）**：4-1（通常時）と4-3（DEF-30%時）を同キャラ・同スキル・
  同難易度で比較した結果。DEFとダメージが単純な1次関係でないことは確定したが、正確な変換式は未確定（B表・5-1参照）。
- **会心ダメージ倍率の整合性チェックでキャラ差が判明**：4-4の現行実測会心%から計算した会心倍率と、4-2のコスモゲート検証時点の
  会心/非会心比率を比べると、ベルリースはほぼ一致するがティリア・バニクレ・セイラは軒並り低い。4-4は4-2と同時期のデータと確認済み
  なので、時期差では説明できない。ベルリースだけ一致する理由も含め、原因は引き続き未確定（A表・5-2参照）。
- **HARD難易度は「ダメージ＝ATK×atk_pct%」だけでほぼ説明できる（ベルリースで直接照合）**：atk_pct登録済み・生ATK判明済みの
  ベルリースについて、ATK×atk_pct%（最も単純な予測式）とHARD実測（非会心）を比較したところ、基本/特殊/究極の3スキルとも倍率が
  0.99〜1.08（平均1.03）とほぼ1.0に収まった。一方EASY難易度では3スキルとも倍率が1.455〜1.513（平均1.485）とスキルによらず一律に
  高く、防御力の効果はスキル非依存の乗算項らしいという見立てを補強する。HARD（倍率≈1.0）・HARDでDEF-30%（倍率≈1.16〜1.18）・
  EASY（倍率≈1.485）の3点が並び、DEF値が分かれば変換式をかなり絞り込めそうな段階まで来た（B表・5-3参照）。
